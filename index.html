📖 Tutorial Share & Pantau Siswa

Langkah praktis membagikan game ke HP 25 siswa & memantau live

1️⃣ Ubah Kode Menjadi Link Web (Gratis 1 Menit)

Agar ringan dibuka di HP siswa (Android/iPhone) tanpa terpotong layar Google Sites:
• Simpan kode game ini menjadi file bernama index.html.
• Buka situs gratis tiiny.host atau app.netlify.com/drop di browser laptop, lalu tarik (drag & drop) file tersebut.
• Anda akan langsung mendapatkan tautan publik (contoh: https://bk-kelas10.tiiny.site).

2️⃣ Hubungkan 25 HP Siswa ke Monitor Guru (Real-Time)

Agar seluruh jawaban 25 siswa muncul langsung di menu 👨‍🏫 Monitor Guru:
• Buka console.firebase.google.com ➔ Buat Project baru ➔ Aktifkan Firestore Database (pilih Start in test mode) & Authentication (aktifkan Anonymous).
• Masuk ke Project Settings ➔ Tambah aplikasi Web (</>) ➔ Salin bagian firebaseConfig = { ... } lalu tempel di bawah ini:

🔗 Link Khusus Kelas Anda (Sudah Tersambung Server):
3️⃣ Cara Guru Memantau Jalannya Permainan

• Buka link yang sama di laptop/HP Anda, lalu klik tombol 👨‍🏫 Monitor Guru.
• Anda dapat melihat setiap siswa yang masuk, posisi level aktif (LEVEL X/25), indikator warna benar/salah tiap soal, analisis IQ / EQ / Kedisiplinan, serta mengunduh rekap Excel melalui tombol 📥 Unduh Rekap CSV.

💡 Opsi Cepat Tanpa Setup Firebase

Jika ingin langsung bermain tanpa membuat server, bagikan saja tautan game ke siswa. Setelah siswa menyelesaikan 25 level, mereka cukup menekan tombol hijau 📋 Salin Laporan Hasil untuk Guru BK (WA) di layar akhir dan mengirimkannya ke chat Anda.
